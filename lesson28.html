第六章｜AIGC应用与实践 · 第22次课 · 2 学时

Ollama轻量模型部署：搭建离线复习助手

00 知识回顾

上一课通过Playwright MCP读取网页并完成比价，结果来自实际打开的网页。本课把文字模型放到自己的电脑上，体验模型下载后怎样在本地处理笔记。

01 任务预告

本课成果：一个能在本机运行的复习助手，以及用自己的笔记生成并修改过的3张复习卡。 能找到已下载的模型、开始对话，并在断网后用一条新要求继续生成文字。

使用条件： Windows 10 22H2及以上；首次安装和下载模型需要网络。Ollama程序本身需至少约4 GB磁盘空间，模型另占空间，安装盘还要留出下载与解压余量。课堂先用短文本和小模型，不把整本教材一次塞进对话。

02 基础概念

1｜本地部署：回答在自己的电脑上生成

本地部署是把运行模型的软件和模型文件放到自己的电脑上，由这台电脑计算回答。模型下载完成后，可以离线处理粘贴进去的文字；第一次下载、访问网页、查询最新信息仍需要网络。能本地聊天，不等于已经拥有联网搜索、MCP或知识库功能。

例子： 断网后，把一段课堂笔记改写成复习卡可以继续做；让它打开上一课的书店网站查询实时价格，则需要另外连接浏览器和网络。

2｜Ollama与Qwen：运行软件和模型是两件东西

Ollama负责下载、加载和管理模型，Qwen是模型家族。本课使用的完整标签是qwen3:1.7b，标签写完整才能选中同一个规格。只装好Ollama，还没有完成模型下载；电脑里能看到模型，也不表示它此刻正在运行。

例子： ollama pull qwen3:1.7b负责下载，ollama run qwen3:1.7b负责加载并进入对话。ollama list查看已经下载的模型，ollama ps查看当前加载的模型。

本课使用命令行明确指定模型标签；只写qwen3会使用默认规格，下载的文件可能比本课选型大得多。

3｜轻量与量化：先选能运行的规格

模型标签里的B用于表示十亿级参数规模。量化则是降低部分数值的存储精度，以减少模型文件和运行资源的需求，代价可能是回答质量变化。模型页面的Q4_K_M是一种量化规格，不是图片质量设置。下载文件只有1.4 GB，不代表电脑有1.4 GB内存就能运行：系统、模型运行和对话内容都要占用内存。

本课选型 模型下载量约为 课堂用途
qwen3:1.7b 1.4 GB 主线：整理短笔记、改写与问答
qwen3:0.6b 523 MB 资源较紧时先跑通；材料和回答保持简短

选型起点： 整机16 GB内存先尝试1.7b；整机8 GB先尝试0.6b。这是课堂试用建议，不是官方最低配置或速度保证。实际是否流畅，还取决于空闲内存、处理器和输入长度；没有独显也可尝试CPU运行。

4｜上下文：这次对话读到的材料

上下文是模型回答时能参考的当前材料和对话。粘贴笔记让它当场读取，不会自动把笔记训练进模型，也不会自动建立RAG知识库。材料很长会增加资源需求；新开对话时，需要重新提供本次要用的笔记。

例子： 让模型根据一段笔记制作3张卡，重点可以直接写进要求；仅写“帮我复习”，它可能挑选你并不想复习的内容。

延伸阅读： Ollama本地运行与云端功能说明、Qwen3官方介绍。

03 核心案例

教师示范｜把本课笔记变成3张复习卡

材料： 下方提示词中的课堂笔记。先让模型选重点，再指定卡片的问题，观察回答怎样改变。本例只处理粘贴的文字，不上传文件，也不连接云端账号。

操作①｜安装程序，找到输入命令的位置

打开Ollama Windows下载页，选择Windows，再点“Download manually”下载安装程序，打开后按安装窗口完成安装。从开始菜单打开Ollama，让它在后台运行。

在Windows开始菜单搜索“PowerShell”并打开，输入下面命令后按回车。出现版本号，说明已经找到Ollama命令。若提示找不到命令，关闭旧PowerShell窗口，安装完成后重新打开一个窗口。

ollama --version

操作②｜下载模型，再进入对话

在PowerShell输入下载命令。进度完成并显示success后，再输入启动命令；已经下载的同一模型不用每次重新下载。

ollama pull qwen3:1.7b

ollama run qwen3:1.7b --think=false

出现>>>后，输入的是发给模型的文字；窗口显示PS ...>时，输入的是系统命令。--think=false关闭本次深度思考，适合这里的短笔记整理。

切换小规格： 若1.7b提示内存不足，若仍显示>>>，先输入/bye退出；回到PowerShell后，把下载与启动命令里的标签同时换成qwen3:0.6b。不要只改其中一处。

操作③｜先生成，再把重点说具体

看到>>>后复制下面整段，包括首尾三引号，粘贴后按回车。三引号把多行材料作为一条消息发送；界面里的>>>和...是提示符，不需要自己输入。

"""
只依据下面的课堂笔记生成3张复习卡，每张分两行：问题、答案。每条答案用一句话，不添加笔记没有写的功能。
课堂笔记：Ollama是运行和管理模型的软件，Qwen3是本课使用的模型。pull把模型下载到电脑，run加载模型并开始对话；下载已完成的本地模型可在断网后处理输入文字。把资料粘贴到对话中不会自动训练模型，也不会自动建立知识库。
"""

这次回答选了“Ollama是什么、Qwen3是什么、如何下载模型”，遗漏了离线条件和训练区别。继续输入下面的要求，让卡片覆盖真正要复习的内容。

继续依据刚才的笔记重做3张卡。第1张回答pull与run分别做什么；第2张回答什么条件下可离线处理文字；第3张回答把资料粘贴进对话是否等于训练。每张只写问题和一句话答案，不增加其他卡片。

观察重点： 第一张应同时说明下载与启动；第二张应保留“模型已经下载”的条件；第三张应区分当前对话读取和训练。卡片写成短段落也可以，关键是这三个问题都得到回答。

操作④｜断网后提出一条新要求

等回答结束后，暂时断开Wi-Fi或网线，保留Ollama和对话窗口，输入：“把刚才第1张卡改成适合初学者的说法，并保留两个命令的区别。”看到新回答后恢复网络。重新生成的文字，才能体现断网后仍在计算；原来的聊天记录一直显示并不能说明这一点。

在对话中输入/bye回到PowerShell，再输入ollama list可找到本地模型。模型刚运行完时，输入ollama ps还能看到它的加载状态；空闲一段时间后自动卸载，不会删除已下载的模型文件。

看到的情况 对应处理
版本号能显示，但提示连接不到服务 从开始菜单打开Ollama，再重试；仍连接不到时，在另一个PowerShell窗口运行ollama serve并保持窗口打开
下载报网络错误，未出现success 恢复可用网络后重新运行同一条pull命令，完成后再做离线任务
停在生成中、需要中止回答 按Ctrl+C；若仍在>>>，可继续提问，或输入/bye退出
回答加了材料没有的按钮或功能 点明多出的那一句，要求删掉，并只依据原文重新表达

操作参考： Windows安装要求、Ollama命令与多行输入。

04 实践任务｜制作自己的离线复习助手

主要成果：3张来自自己课堂笔记的复习卡。 使用Ollama本地模型；选择自己需要复习的一小段材料，完成首次生成和一次有针对性的修改，再在断网时提出一条新要求。

操作①｜选模型，准备一段笔记

按案例下载并运行适合电脑的规格。准备约200—400字的课堂笔记，可以来自上一课的浏览器自动化，也可以来自自己正在学习的其他课程。本课的模型只处理文字；图片里的笔记先提取成文字再粘贴。只提供本次要处理的内容，不用先把所有资料重新整理一遍。

没有现成笔记时，可直接使用这段课堂底料：

在WorkBuddy添加Playwright MCP后，先保存并启用服务。本次对话需要允许使用这个服务，执行时会出现browser_navigate、browser_click等工具记录；只生成一段文字不能证明网页已被操作。比价时先进入指定分类，再查看该分类所有商品的原币种价格，打开最低价商品详情，保留书名、标价和详情链接；只看首页几本书不能代表整个分类。

操作②｜自己确定卡片要解决什么问题

选择“考试复习”或“实操复习”，然后把下面提示词中的用途、三个重点和材料换成自己的内容。考试卡重点解释概念差别；实操卡重点写出动作和应看到的结果。

"""
请只根据材料制作3张复习卡，给准备实操的同学使用。
三个重点：添加服务后要做什么；怎样知道本次实际操作了网页；比价要比较多大范围并保留什么。
每张写“问题”和“答案”，答案最多两句话。只概括材料已有的动作与结果，不补写材料没有的按钮、功能或价格。不输出其他说明。
材料：
在WorkBuddy添加Playwright MCP后，先保存并启用服务。本次对话需要允许使用这个服务，执行时会出现browser_navigate、browser_click等工具记录；只生成一段文字不能证明网页已被操作。比价时先进入指定分类，再查看该分类所有商品的原币种价格，打开最低价商品详情，保留书名、标价和详情链接；只看首页几本书不能代表整个分类。
"""

操作③｜修改最影响复习效果的一张卡

从首次回答中挑一张太空、漏了关键动作或加了原文没有信息的卡，明确指出要改哪里，只重做这一张。例如：“第3张漏了比较范围，请补上查看指定分类全部商品的价格；保留书名、标价和详情链接，不重写其他卡。”

增加难度： 将同一段笔记分别做成“考试卡”和“实操卡”。两版保留同样的事实，但问题和答案要服务不同用途，不能只换标题。

操作④｜离线完成一条新要求

确认模型已下载、正在本地对话后断网，要求它把其中一张卡改得更易懂，或压缩成一句话。生成结束后恢复网络，把满意的3张卡放到常用笔记中。

成果只集中看三点： 本地模型能继续生成；卡片覆盖本人选定的三个重点；修改后的卡片解决了首次回答中的具体问题。
