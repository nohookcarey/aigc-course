今天要完成什么？

  • 最终作品：一份带有交叉核对公式、一张规范柱状图和两条真实数据发现的销售分析表。
  • 交作业文件名：12_产品销售比较图_姓名.xlsx
  • 合格标准（看这5条）：
    1. 包含 销售练习 和 AI过程记录 两个独立工作表；
    2. D2:D4 单元格计算各月合计（200、240、240元），B8:B9 计算各产品季度总额（400、280元）；

避坑预警：借助 AI 辅助可视化时的常见偏差

利用 AI 可以帮我们快速构思图表方案与提炼文字，但若提示词缺乏严谨约束，AI 容易产生以下 4 类典型偏差，需要我们在实操中主动规避：

四大常见偏差与应对对照表

常见偏差现象 产生原因分析 提示词约束示范 我们的实操动作
❌ 1. 坐标轴未从 0 起始 纵坐标从 270 开始，微小的数值差异在视觉上被过度放大 “生成柱状图方案，垂直纵坐标轴必须强制从 0 起始，严禁截断。” 在 WPS 中双击垂直坐标轴，在坐标轴属性中确认最小值为 0。
❌ 2. 选区混入合计项 未精准框选对比项，导致图表中多出一根巨大的“合计”柱子 “仅对比 A 与 B 两款产品的总额，数据源严格限定为 A7:B9。” 选定数据时仅框选产品名称与对应数值，不包含总计行。
❌ 3. 核对总数被二次累加 横向合计 680 与纵向合计 680 在核验后被错误加总为 1360 “横向与纵向汇总仅用于平衡核验，业务总额只计算一次。” 明确总销售额为 680 元，两路计算用于防错校验，绝不再加。
❌ 4. 脱离数据主观臆测 仅有销售额数据，AI 却自动补充“质量更佳、利润大幅增长” “仅基于表格数字提取客观发现，未提供成本信息严禁推断利润。” 数据发现聚焦差额对比与最高月份，不写入未经佐证的主观推断。

02 基础概念

概念 1｜分类角度（维度）与统计数值（指标）

在数据处理中，清晰区分两个基本概念能帮助我们理清思路：

  • 维度（观察角度）：指我们从哪个方面来切片观察数据，例如按“月份”（1月、2月、3月），或者按“产品”（A产品、B产品）；
  • 指标（统计数值）：指具体用来衡量的数字大小，例如“销售额（元）”。

向管理层汇报前，先明确业务核心目标，再选择合理的分类维度进行统计，能够让数据结论更具针对性。

概念 2｜横向与纵向汇总的交叉核对

横向按月份将各产品加总：1月 200 元、2月 240 元、3月 240 元，三个月总计为 680 元。

纵向按产品将各月份加总：A产品 400 元、B产品 280 元，两款产品总计同样为 680 元。

横向与纵向计算得出的总额完全一致（均为 680 元），即证明底层数据没有发生遗漏或重复，这就是职场中经典的“交叉核对法”。这两路数据用于互相验证准确性，不可再次相加。

概念 3｜实用柱状图制作的三个要点

在商务报告中，制作柱状图应当遵循三项基本规范：

  1. 垂直 Y 轴必须从 0 起始：柱状图利用柱体的长短直观反映数值规模。如果截断坐标轴（例如从 270 开始），会造成微小差距的视觉夸大，影响管理层的正确判断。
  2. 精准选取数据源（仅选 A7:B9）：本次分析的核心是比较 A/B 两款产品的总额，因此应仅选取产品名称与对应的汇总数字，避免将各月明细或总计行混合选中。
  3. 图表合理布局防遮挡：生成图表后将其放置在数据表格下方（如第 16 行以下），标注清晰的标题与单位，确保原始表格与可视化图表均能一目了然。

概念 4｜用数据事实说话，区分客观与推测

在撰写数据汇报时，务必坚持“有多少数据，说明多少事实”的原则：

  • 客观事实：1—3月 A 产品销售额为 400 元，B 产品为 280 元，A 比 B 多 120 元；2月与3月单月销售额均为 240 元，并列为季度最高月份。
  • 主观推测：在未掌握采购成本、营销费用及用户满意度等前提下，不能直接断言“A产品利润更高”或“A产品质量更好”。严谨的职业习惯是仅陈述已有数据支持的事实，将未证实事项作为“后续待核实点”。
💡 思考探究

看到 A 卖了 400 元，B 卖了 280 元，AI 在总结里写道：“A产品深受大家喜爱，为公司赚了极多净利润，建议以后削减 B 产品的进货”。如果你是组长，能把这段话直接报给领导吗？为什么？

不宜直接呈报，原因主要有三点：

  1. 销售额不等于实际利润：当前表格仅反映销售总额，并未提供进货成本。若 A 产品属于低毛利引流品、B 产品属于高毛利商品，A 的实际利润未必高于 B。
  2. 缺乏支撑依据的质量评价：表格中没有售后退换率或客户评价数据，断定其质量好坏缺乏数据依托。
  3. 专业修正建议：客陈述数据事实——“一季度 A 销售额 400 元，比 B 产品多 120 元；两款产品的盈利贡献，建议结合成本核算表作进一步分析”。

03 核心案例

典型场景分析：周末两天销售额并列第一，能否仅突出单日？

某项目义卖三天收入为：周五 90 元、周六 120 元、周日 120 元。AI 提炼的汇报写道：“周六以 120 元位列第一，反映出周六宣传效果最佳”。

偏差分析与规范做法

  • 偏差所在： 周六与周日销售额完全相同，属于并列第一；且在未统计人流的前提下，直接将销售提升归因于宣传，属于缺乏根据的主观判断。
  • 规范做法：
    1. 客观反映周六与周日并列第一（均为 120 元），均比周五多 30 元；
    2. 在分析中说明：“关于销售提升的具体成因，需结合到店人流与营销排期做进一步印证”。

数据呈现与分析五步法

  1. 基础录入：将各维度原始明细准确录入表格；
  2. 拟定方案：要求 AI 提供对比方案，明确从 0 起始并指出并列情况；
  3. 方案核验：审查 AI 是否准确把握分析边界与图表要求；
  4. 图表实装：在 WPS 中插入柱状图，设置标题并核验坐标轴；
  5. 提炼发现：撰写客观严谨的数据事实，不随意主观推论。

04 实践任务｜动手完成 A/B 产品汇总与柱状图制作

协同工具分工与规范留痕

  • AI 协同软件（明确使用 WorkBuddy）：本课统一使用 WorkBuddy 客户端，负责协助规划分析维度、提供图表生成步骤建议与客观提炼参考；
  • 表格处理软件：使用 WPS 表格，完成公式配置、图表绘制、布局微调与分析陈述录入；
  • 为什么建“AI过程记录”？ 记录人机协同的思考过程与核验结论，是企业数字化分析中“结论可复溯”的重要规范体现。

第 1 步｜下载练习表，建立过程记录表

  1. 下载练习表格（本课统一通过下载获取表格，无需手动录入原始数据）：
    • 学习通位置：登录超星学习通 ➔ 进入**《AIGC 应用与实践》课程 ➔ 点击“资料”** ➔ 进入**“人工1、2班，课程课件”**文件夹 ➔ 下载 第12次课_销售数据练习表(1).xlsx。
  2. 用 WPS 打开下载好的练习表，保持 销售练习 工作表内容不动，点击底部 + 号新建工作表，重命名为 AI过程记录；
  3. 在新工作表的 A1 至 A5 单元格中，依次录入 5 个栏目名称：原材料、AI计划、审查结论、整理草稿、核对记录。

第 2 步｜输入提示词 A，获取分析规划

打开 WorkBuddy 对话框，复制下方提示词 A 发送给 WorkBuddy：

请针对销售数据练习表中的数据，先制定数据汇总与图表制作的处理计划，暂不生成最终草稿或执行文件。

要求：
1. 分析目标：对比 A 与 B 两款产品在一季度的总销售额，制作一张簇状柱形图；
2. 汇总方法：横向按月份汇总、纵向按产品汇总，两路总额仅做交叉核对，不重复累加；
3. 图表要求：数据源仅选中产品汇总行（展示 A 与 B 两根柱体），纵坐标轴从 0 起始，图表置于下方空白处；
4. 数据发现：总结两条客观事实（A比B多120元，2月与3月并列最高240元），未提供成本时不推测利润高低；
5. 说明需经人工确认，不直接声称完成文件操作。

第 3 步｜人工核验：把关可视化方案

对照以下 3 项标准核验 AI 给出的计划：

  1. 对比重点是否突出？ 确认图表聚焦于 A 与 B 两款产品的总额对比；
  2. 基准设定是否合规？ 确认方案中明确了 Y 轴从 0 开始；
  3. 数据描述是否客观？ 确认方案中准确识别了 2 月与 3 月的并列关系，未出现缺乏支撑的主观推论。

第 4 步｜获取参考草稿并在表格中绘制图表

向 WorkBuddy 发送提示词 B，获取操作指引与数据提炼参考：

方案已确认。请根据确认的规则输出汇总结果建议，包含月度与产品汇总数据、图表绘制要点及两条客观数据发现。

要求：
1. 给出 D2:D4 与 B8:B9 的计算公式及数值，明确两路交叉核对结果均为 680 元；
2. 明确柱状图操作建议：选区 A7:B9、簇状柱形图、纵轴从 0 起始、规范标题；
3. 输出两条客观数据发现（A比B多120元、2月与3月并列最高240元）；
4. 仅提供文本参考，不声称已在本地保存文件。

切回 WPS 表格，完成以下实操动作：

  1. 配置求和公式（确保输入法为半角英文状态）：
    • 选中 D2 输入 =SUM(B2:C2) 按回车（结果为 200）；选中 D3 输入 =SUM(B3:C3) 回车（240）；选中 D4 输入 =SUM(B4:C4) 回车（240）；
    • 选中 B8 输入 =SUM(B2:B4) 按回车（结果为 400）；选中 B9 输入 =SUM(C2:C4) 回车（280）；
    • 完成交叉核对：产品总计 400 + 280 = 680 元，各月总计 200 + 240 + 240 = 680 元。两路总额一致，核验完成。
  2. 插入簇状柱形图：
    • 用鼠标准确选定 A7:B9 区域（仅包含表头、A/B两行产品名称与对应数值）；
    • 点击顶部菜单栏 插入 ➔ 图表 ➔ 选择 柱形图 ➔ 点击第一个 簇状柱形图。
  3. 规范标题与位置微调：
    • 双击图表标题，修改为：1—3月A/B产品销售额比较（元）；
    • 确认垂直 Y 轴最小值是否从 0 起始（若不是，双击坐标轴在右侧属性中将最小值设为 0）；
    • 拖拽图表边框，平移放置在第 16 行以下空白区域，保持上方数据表清晰完整。
  4. 录入两条客观数据发现（在图表下方单元格如 A28 录入）：
    • 发现一：一季度 A 产品销售额为 400 元，B 产品为 280 元，A 产品较 B 产品多出 120 元。
    • 发现二：2月与3月销售额均为 240 元，并列为一季度销售最高月份。材料未包含成本数据，利润表现需结合成本表核算。

第 5 步｜规范命名保存与复核检查

  1. 点击 WPS 菜单栏 文件 ➔ 另存为；
  2. 保存类型选择 Excel 文件 (*.xlsx)；
  3. 将文件名命名为：12_产品销售比较图_姓名.xlsx；
  4. 点击保存后，关闭 WPS 软件；
  5. 重新双击打开文件，确认工作表、图表与文字发现均正常展示。
