第六章｜AIGC应用与实践 · 第25次课 · 2 学时

Ollama轻量模型部署：搭建离线复习助手

00 知识回顾

上一课比较了交付一份成品、提供一个工具和接入业务系统的区别。无论做哪一种应用，都要考虑模型在哪里运行。本课把文字模型放到自己的电脑上，试着在没有网络时继续整理笔记。

01 任务预告

本课成果：一个能在本机运行的复习助手，以及用自己的笔记生成并修改过的3张复习卡。 你要能选对模型、进入对话，让卡片覆盖自己选定的三个重点，并在断网后用一条新要求继续生成文字。

使用条件： Windows 10 22H2及以上；首次安装和下载模型需要网络。Ollama程序本身需至少约4 GB磁盘空间，模型另占空间，安装盘还要留出下载与解压余量。课堂先用短文本和小模型，不把整本教材一次塞进对话。

开始前先看电脑里有没有模型： 已安装Ollama的同学直接打开PowerShell，输入ollama list。列表中已有本课规格就从启动对话开始；没有才下载。下载仍未完成时，先使用同桌已准备好的电脑完成提问与修改，再在自己的电脑补做部署。

02 基础概念

1｜本地部署：回答在自己的电脑上生成

本地部署是把运行模型的软件和模型文件放到自己的电脑上，由这台电脑计算回答。模型下载完成后，可以离线处理粘贴进去的文字；第一次下载、访问网页、查询最新信息仍需要网络。能本地聊天，不等于已经拥有联网搜索、MCP或知识库功能。

例子： 断网后，把一段已经粘贴进去的课堂笔记改写成复习卡可以继续做；让它查询今天的商品价格，则需要另外连接网络和检索工具。它也不会因为运行在本机，就自动读到电脑上的所有文件。

2｜Ollama与Qwen：运行软件和模型是两件东西

Ollama负责下载、加载和管理模型，Qwen是模型家族。本课使用的完整标签是qwen3:1.7b，标签写完整才能选中同一个规格。只装好Ollama，还没有完成模型下载；电脑里能看到模型，也不表示它此刻正在运行。

例子： ollama pull qwen3:1.7b负责下载，ollama run qwen3:1.7b负责加载并进入对话。ollama list查看已经下载的模型，ollama ps查看当前加载的模型。

本课使用命令行明确指定模型标签；只写qwen3会使用默认规格，下载的文件可能比本课选型大得多。

想知道什么 在PowerShell输入 结果说明什么
电脑里存了哪些模型 ollama list 已下载到磁盘，可以准备启动
此刻加载了哪些模型 ollama ps 正在占用运行资源，可能处于等待提问状态

下载后的模型像存好的软件材料，运行时还要加载到内存。退出对话后，模型可能暂时留在内存；空闲一段时间自动卸载，并不等于磁盘里的模型被删除。

3｜轻量与量化：先选能运行的规格

模型标签里的B用于表示十亿级参数规模。量化则是降低部分数值的存储精度，以减少模型文件和运行资源的需求，代价可能是回答质量变化。模型页面的Q4_K_M是一种量化规格，不是图片质量设置。下载文件只有1.4 GB，不代表电脑有1.4 GB内存就能运行：系统、模型运行和对话内容都要占用内存。

本课选型 模型下载量约为 课堂用途
qwen3:1.7b 1.4 GB 主线：整理短笔记、改写与问答
qwen3:0.6b 523 MB 资源较紧时先跑通；材料和回答保持简短

选型起点： 整机16 GB内存先尝试1.7b；整机8 GB先尝试0.6b。这是课堂试用建议，不是官方最低配置或速度保证。实际是否流畅，还取决于空闲内存、处理器和输入长度；没有独显也可尝试CPU运行。

选模型时，在1.7b模型页或0.6b模型页核对完整标签、下载大小和输入类型。本课这两个规格处理文字；换成小模型后，要重新看回答有没有漏掉关键内容。

4｜上下文：这次对话读到的材料

上下文是模型回答时能参考的当前材料和对话。粘贴笔记让它当场读取，不会自动把笔记训练进模型，也不会自动建立RAG知识库。材料很长会增加资源需求；新开对话时，需要重新提供本次要用的笔记。

训练会改变模型的参数；本课只是把笔记作为当前对话材料。RAG知识库则需要额外建立资料检索流程，先找出相关片段，再把片段交给模型。本课直接粘贴短笔记，不需要搭建这套流程。

例子： 让模型根据一段笔记制作3张卡，重点可以直接写进要求；仅写“帮我复习”，它可能挑选你并不想复习的内容。

延伸阅读： Ollama本地运行与云端功能说明、Qwen3官方介绍。

03 核心案例

教师示范｜把本课笔记变成3张复习卡

材料： 下方提示词中的课堂笔记。先生成卡片，再指定卡片的问题，观察要求怎样改变回答。本例只处理粘贴的文字，不上传文件，也不连接云端账号。

操作①｜安装程序，找到输入命令的位置

打开Ollama Windows下载页，选择Windows，再点“Download manually”下载安装程序，打开后按安装窗口完成安装。从开始菜单打开Ollama，让它在后台运行。

在Windows开始菜单搜索“PowerShell”并打开，输入下面命令后按回车。出现版本号，说明已经找到Ollama命令。若提示找不到命令，关闭旧PowerShell窗口，安装完成后重新打开一个窗口。

ollama --version

先认输入位置： 后面会在同一个窗口中切换两种状态。PS ...>表示PowerShell在等系统命令；>>>表示模型在等你的问题。提示符由窗口显示，不要一起复制。

窗口显示 可以输入什么
PS ...> ollama pull、ollama run、ollama list等命令
>>> 课堂笔记、生成要求和追问；输入/bye返回PowerShell
... 三引号包住的多行消息还没结束，继续粘贴剩余内容

操作②｜下载模型，再进入对话

在PowerShell输入下载命令。进度完成并显示success后，再输入启动命令；已经下载的同一模型不用每次重新下载。run找不到本地模型时也会尝试下载，本课把两步分开，方便判断下载是否完成。

ollama pull qwen3:1.7b

ollama run qwen3:1.7b --think=false

出现>>>后，输入的是发给模型的文字；窗口显示PS ...>时，输入的是系统命令。--think=false关闭本次深度思考，适合这里的短笔记整理。

切换小规格： 若1.7b提示内存不足，若仍显示>>>，先输入/bye退出；回到PowerShell后，把下载与启动命令里的标签同时换成qwen3:0.6b。不要只改其中一处。

操作③｜先生成，再把重点说具体

看到>>>后复制下面整段，包括首尾三引号，粘贴后按回车。三引号把多行材料作为一条消息发送。若粘贴后仍显示...，检查最后一行是否有三个英文双引号，再按回车。

"""
只依据下面的课堂笔记生成3张复习卡，每张分两行：问题、答案。每条答案用一句话，不添加笔记没有写的功能。
课堂笔记：Ollama是运行和管理模型的软件，Qwen3是本课使用的模型。pull把模型下载到电脑，run加载模型并开始对话；下载已完成的本地模型可在断网后处理输入文字。把资料粘贴到对话中不会自动训练模型，也不会自动建立知识库。
"""

模型可能先选“Ollama是什么、Qwen3是什么、如何下载模型”，却没有覆盖你真正想复习的区别。先看它选了哪些重点，再继续输入下面的要求，把三张卡的分工说清楚。

继续依据刚才的笔记重做3张卡。第1张回答pull与run分别做什么；第2张回答什么条件下可离线处理文字；第3张回答把资料粘贴进对话是否等于训练。每张只写问题和一句话答案，不增加其他卡片。

观察重点： 第一张应同时说明下载与启动；第二张应保留“模型已经下载”的条件；第三张应区分当前对话读取和训练。卡片写成短段落也可以，关键是这三个问题都得到回答。

例如，第2张的答案可以表达为：“先下载好本地模型，再由本机加载运行，就能在断网后处理输入的文字。”这是一种内容写法，实际措辞可以不同；不要把“支持离线”改成“不用下载也能使用”。

操作④｜断网后提出一条新要求

等回答结束后，暂时断开这台电脑的Wi-Fi或网线，保留Ollama和对话窗口；同时开着手机热点或其他网络连接时，也要先断开它。然后发送下面这条新要求，看到新回答后恢复网络。

把刚才第1张卡改成适合初学者的说法，用“先……再……”说明pull与run的区别，保留两个命令的名称，只重写这一张卡。

在对话中输入/bye回到PowerShell，再输入ollama list可找到本地模型。模型刚运行完时，输入ollama ps还能看到它的加载状态；空闲一段时间后自动卸载，不会删除已下载的模型文件。

看到的情况 对应处理
版本号能显示，但提示连接不到服务 从开始菜单打开Ollama，再重试；仍连接不到时，在另一个PowerShell窗口运行ollama serve并保持窗口打开
下载报网络错误，未出现success 恢复可用网络后重新运行同一条pull命令，完成后再做离线任务
输入list或pull后，模型开始解释这几个词 当前仍在>>>对话中；输入/bye回到PowerShell，再输入完整命令
启动时提示内存不足，或长时间没有输出 关闭占用较多资源的程序，缩短材料；仍无法运行时改用0.6b，或在已准备好的同桌电脑完成生成
停在生成中、需要中止回答 按Ctrl+C；若仍在>>>，可继续提问，或输入/bye退出
回答加了材料没有的按钮或功能 点明多出的那一句，要求删掉，并只依据原文重新表达

操作参考： Windows安装要求、Ollama命令与多行输入。

04 实践任务｜制作自己的离线复习助手

主要成果：3张来自自己课堂笔记的复习卡。 使用Ollama本地模型；选择自己需要复习的一小段材料，完成首次生成和一次有针对性的修改，再在断网时提出一条新要求。

操作①｜选模型，准备一段笔记

按案例下载并运行适合电脑的规格。准备约200—400字的课堂笔记，可以来自前面学过的浏览器自动化，也可以来自自己正在学习的其他课程。本课的模型只处理文字；图片里的笔记先提取成文字再粘贴。只提供本次要处理的内容，不用先把所有资料重新整理一遍。

没有现成笔记时，可直接使用这段课堂模拟笔记。它来自日常整理学习文件的情境，任务与教师示范不同，但仍采用“短笔记→三张卡→定向修改”的方法。

【课堂模拟笔记】学习文件的备份与整理：备份是在另一个位置保留一份可以恢复的副本。只把原文件改名或移到另一个文件夹，没有增加第二份副本，不能算完成备份。修改重要文件前，先复制并保留原版，再编辑工作副本。文件名可以写清内容、版本或日期，方便区分，日期应使用实际日期。覆盖旧版前，打开新版确认内容正常，同时保留需要恢复的旧版。把两份文件都放在同一块硬盘，能应对部分误删，但硬盘损坏时两份都可能丢失；重要资料还要保存在另一块存储设备或可信的同步位置。使用云同步时应查看历史版本和误删恢复范围，不能假定删除文件后一定能找回。

操作②｜自己确定卡片要解决什么问题

选择“考试复习”或“实操复习”，然后把下面提示词中的用途、三个重点和材料换成自己的内容。考试卡重点解释概念差别；实操卡重点写出动作和应看到的结果。使用模拟笔记时，可直接复制下面完整提示词，不需要再粘贴上一段。

"""
请只根据材料制作3张复习卡，给准备实操的同学使用。
三个重点：怎样区分移动与备份；修改重要文件前保留什么；为什么同一块硬盘上的两份文件仍有风险。
每张写“问题”和“答案”，答案最多两句话。只概括材料已有的动作与结果，不补写材料没有的操作或结论。不输出其他说明。
材料：
【课堂模拟笔记】学习文件的备份与整理：备份是在另一个位置保留一份可以恢复的副本。只把原文件改名或移到另一个文件夹，没有增加第二份副本，不能算完成备份。修改重要文件前，先复制并保留原版，再编辑工作副本。文件名可以写清内容、版本或日期，方便区分，日期应使用实际日期。覆盖旧版前，打开新版确认内容正常，同时保留需要恢复的旧版。把两份文件都放在同一块硬盘，能应对部分误删，但硬盘损坏时两份都可能丢失；重要资料还要保存在另一块存储设备或可信的同步位置。使用云同步时应查看历史版本和误删恢复范围，不能假定删除文件后一定能找回。
"""

操作③｜修改最影响复习效果的一张卡

从首次回答中选一张最需要改进的卡，明确指出要改哪里，只重做这一张。可修改遗漏、用词或说明方式；初稿已准确时，改成同学更容易照着做的表达，不必故意制造错误。

例如：“第3张只写了多存一份，请补充同一块硬盘损坏时两份都可能丢失，说明要把重要资料保存在另一块存储设备或可信的同步位置。只重写第3张，答案不超过两句话。”

增加难度： 将同一段笔记分别做成“考试卡”和“实操卡”。两版保留同样的事实，但问题和答案要服务不同用途，不能只换标题。

操作④｜离线完成一条新要求

确认模型已下载、正在本地对话后断网，要求它把其中一张卡改得更易懂，或压缩成一句话。生成结束后恢复网络，把满意的3张卡放到常用笔记中。

成果只集中看三点： 断网后的新要求得到了新回答；卡片覆盖本人选定的三个重点且没有补写原文外信息；修改后的卡片解决了具体问题或更适合选定用途。部署卡住时，记录看到的错误，按上面的对应处理继续；换用同桌电脑完成生成，只说明你完成了生成练习。
